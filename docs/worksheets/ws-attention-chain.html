Self-attention forward pass — eight steps you can check by hand

Every weight is an integer, so every matrix before the softmax is an integer matrix. The softmax output is the only fractional matrix on the page and is printed to 3 decimals.

Read it in three columns: the left rail is the main line (one row per step: the paper's own formula with this step's block marked, then OP what it does, IN and OUT the tensors it eats and produces), the centre is the matrices that step touches, the right is one worked note. One set of paper symbols names every tensor -- the card formula, the rail's IN/OUT flow and the variable table all print the same name -- and every shape and badge comes from the same trace.

Three independent 4x4 projections. Each entry is a 4-term sum of integers.
Why integers
A figure you cannot check is a very expensive screenshot. Small integer weights keep Q, K, V and every score integral, so a pencil can follow one cell at a time.
The price: no scaling in v0, because dividing by √2 would make every score fractional. meta.scale carries the value (1), so switching it later changes nothing in this renderer.

One score, worked out
\((QK^{\top})[0][2][2] = q_{2}\cdot k_{2} = 1\cdot 0 + 1\cdot(-1) = \mathbf{-1}\)
That is the whole trick of the step above: with d_k = 2 a score is two multiplications and one addition. Do it for the other cells and the score matrices become checkable rather than mystical.
