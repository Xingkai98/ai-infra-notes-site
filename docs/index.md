# AI Infra 讲义

从 Transformer 骨架一路到推理系统的 29 篇讲义，每篇含依赖图、数值例子、面试要点与常见坑。

## 怎么读

1. 左侧按编号顺序读（01 → 29），每篇开头的「依赖图」写明前置
2. 顶部搜索框直接搜术语（例如 `KV cache`、`PD 分离`、`roofline`）
3. 右上角可切深色，手机上同样可用
4. 配套的 [手算卡](worksheets/index.md) 是要打印出来动笔的
